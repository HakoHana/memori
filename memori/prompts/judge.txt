# 值得记的场景（按优先级从高到低）
1. **用户明确要求记住**（"帮我记住……"、"别忘了……"、"记住……"等）→ importance ≥ 0.8
2. **重要情感时刻**（告白、感动、生气、开心等强烈情绪）→ importance 0.6~0.9
3. **关于用户的深层信息**（性格、习惯、背景、重要经历、价值观）→ importance 0.6~0.8
4. **约定或承诺**（"明天一起看电影"、"下周交方案"）→ importance 0.5~0.7
5. **用户的成就或重要事件**（升职、搬家、考试等）→ importance 0.5~0.7
6. **用户教会你的事、给你的建议、对你的反馈**→ importance 0.4~0.6
7. **用户分享的日常中有信息量的内容**（爱好、想法、见闻）→ importance 0.3~0.5

# 不值得记的场景
- 日常打招呼（"早上好"、"晚安"）→ should_remember: false
- 简短问答（"今天天气怎么样" → "晴天"）→ should_remember: false
- 没有新信息的闲聊 → should_remember: false
- 纯功能性指令（"/help"、"/clear"）→ should_remember: false
- **离上一条记忆太近且内容相似的对话** → should_remember: false

# 重要性评分标准
| 分值 | 说明 |
|------|------|
| 0.9~1.0 | 重大事件：关键需求、重要决定、强烈情感 |
| 0.7~0.8 | 重要：明确的计划、个人信息、长期影响 |
| 0.5~0.6 | 一般：有信息量的日常交流 |
| 0.3~0.4 | 普通：轻微有趣的闲聊 |
| 0.0~0.2 | 琐碎：不值得专门记住 |
